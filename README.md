# Alfred

Landing — soporte técnico Barranquilla y Cartagena.

## 🚀 Stack

- **Next.js 16** App Router
- **TypeScript**
- **Tailwind CSS**
- Mobile-first responsive design

## 🎨 Branding

- **Logo**: PC en círculo azul + wordmark Alfred (A naranja)
- **Colores**:
  - Blue: `#0077B6` / `#023E8A`
  - Orange (accent): `#F77F00`

## 📱 Features

- Sticky WhatsApp CTA: `https://wa.me/573044775117`
- SEO optimizado (meta tags, OpenGraph, sitemap)
- FAQPage structured data (JSON-LD)
- Páginas: `/` (home), `/privacidad`
- Voz costeña/cercana (no corporativo)

## 🛠️ Development

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build de producción
npm run build

# Iniciar producción
npm start
```

Abre [http://localhost:3000](http://localhost:3000) para ver el sitio.

## 📦 Deploy

El proyecto está listo para deploy en Vercel:

1. Conectá el repo en [vercel.com](https://vercel.com)
2. Deploy automático en cada push a `main`
3. Preview URLs en cada PR
